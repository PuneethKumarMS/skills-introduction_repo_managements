# Mergington High School Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please follow these steps:

1. **Do not** create a public issue or disclose vulnerability details publicly.
2. Open the repository's **Security** tab and use **Report a vulnerability**.
3. Include a clear description, impact, and reproduction steps in the report.
4. If needed, notify maintainers that a report was submitted without sharing details publicly.

## Response timeline

- We will acknowledge reports within 2 school days.
- We will provide an initial assessment within 5 school days.
- Critical issues affecting sensitive data are prioritized immediately.

## Security updates process

- Dependabot is configured to check Python dependencies weekly.
- Security-related pull requests should be reviewed and merged promptly.
- After merging security fixes, verify application behavior before release.
